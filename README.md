# 🗄️ Python-SQLite

> Repositório dedicado aos meus estudos de **SQLite com Python**.

## 📖 Sobre

Este repositório reúne exercícios, exemplos e projetos desenvolvidos durante meus estudos de integração entre **Python** e **SQLite**.

O objetivo é aprender os principais conceitos de bancos de dados relacionais, desde operações básicas até a construção de aplicações que utilizam persistência de dados.

---

## 🎯 Objetivos

* Aprender os fundamentos de bancos de dados relacionais.
* Dominar a integração entre Python e SQLite.
* Praticar consultas SQL.
* Desenvolver aplicações com persistência de dados.
* Consolidar conhecimentos para projetos voltados à Análise de Dados e desenvolvimento de software.

---

## 📚 Conteúdos

* ✅ Criação de bancos de dados
* ✅ Criação de tabelas
* ✅ Tipos de dados
* ✅ Inserção de registros
* ✅ Atualização de dados (`UPDATE`)
* ✅ Exclusão de registros (`DELETE`)
* ✅ Consultas (`SELECT`)
* ✅ Filtros (`WHERE`)
* ✅ Ordenação (`ORDER BY`)
* ✅ Funções de agregação
* ✅ Agrupamentos (`GROUP BY`)
* ✅ Relacionamentos entre tabelas
* ✅ Integração com Python (`sqlite3`)
* ✅ Projetos práticos
